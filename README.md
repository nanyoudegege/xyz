## 验收口径

每一批至少完成以下检查：

1. 原扫描图像视觉检查，优先复核低置信度正文、图题、标签和表格；
2. 替换目标页旧OCR流，按真实印刷位置重新建立或修复字符坐标；
3. 内容流字符顺序和坐标可回读；
4. 使用保守墨迹掩膜检查字符框，并把未确认项公开列入复核队列；
5. 编辑页可见渲染不变，并进行全书低分辨率回归；
6. 未编辑页、书签、页码标签、批注和页面几何不受影响；
7. 批量模式完成后，仍安排一次全书语义终检。

## 处理节奏

默认按 **50页一个批次** 推进并集中交付，只有出现文件结构损坏、页序异常或无法可靠裁决的系统性问题时才提前停止。
