# Contributing

Use issues to report page-level OCR or coordinate problems. Report only:

- PDF page number and printed page number
- error category (text, punctuation, reading order, coordinate, figure label, regression)
- a short description of the suspected problem
- verification status

Do not upload textbook pages, screenshots containing substantial page content, full corrected text, or derived PDFs. A maintainer can review the local authorized source and record only the resulting metadata here.

A page may be marked complete only after text/coordinate readback and visible-render regression checks pass.
